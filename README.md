# Анализы My Way

Настольное приложение клиники для работы с результатами анализов.
Chromium встроён — ставить ничего дополнительно не нужно.

## Скачать

Последняя версия — на странице **[Releases](../../releases/latest)**.
Скачивание открыто, вход в GitHub не требуется.

| Система | Файл | Что это |
|---|---|---|
| **Windows** | `Echevarne Desktop Setup … .exe` | установщик (рекомендуется) |
| **Windows** | `Echevarne Desktop … .exe` | portable — запускается сразу, без установки |
| **macOS** | `Echevarne Desktop … .dmg` | установка перетаскиванием |
| **macOS** | `… -mac.zip` | распаковать и запустить, без установки |

> macOS — только Apple Silicon (M1/M2/M3…).

## Первый запуск

Приложение не подписано платным сертификатом, поэтому система один раз предупредит
о неизвестном разработчике:

- **Windows:** «Подробнее» → «Выполнить всё равно».
- **macOS:** правый клик по приложению → «Открыть» → «Открыть».

Дальше нажмите **«Проверить результаты»**: откроется окно портала — войдите и, если
появится проверка, пройдите её. После входа приложение покажет исследования за период.

## Приватность

Данные пациентов в интерфейс не выводятся. PDF с результатами хранятся в зашифрованном
виде и в журналы не попадают.
